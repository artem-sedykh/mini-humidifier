## v3.1.6
[![Downloads](https://img.shields.io/github/downloads/artem-sedykh/mini-humidifier/v3.1.6/total.svg)](https://github.com/artem-sedykh/mini-humidifier/releases/tag/v3.1.6)

### Fixed
- Card layout on Home Assistant 2025.10 and newer. Home Assistant replaced the
  slider the target-humidity row is built on, and the row collapsed onto the
  entity name. The card now detects which slider it is running against, so this
  release works on every supported version from 2022.11 onwards - no separate
  build, and nothing to change in your configuration.
- The target-humidity slider drifting away from the entity state after the
  first drag on Home Assistant 2025.10 and newer.
- Icon buttons rendering at the wrong size on Home Assistant 2025.10 and newer.

### Changed
- Documentation reorganised: the README is now a landing page, and the option
  reference lives in [docs/](https://github.com/artem-sedykh/mini-humidifier/tree/master/docs).
  Install instructions, supported models and troubleshooting were out of date
  and have been corrected.
