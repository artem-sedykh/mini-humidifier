Adds a new device, and repairs the mode dropdowns of three models that had
been calling a service Home Assistant removed in 2023.7.

### Added

- Defaults for `xiaomi_miio_airpurifier:deerma.humidifier.jsq5`, contributed
  by @akovovh.

### Fixed

- The mode dropdown doing nothing on
  `xiaomi_miio_airpurifier:deerma.humidifier.mjjsq` and
  `xiaomi_miio:zhimi.airfresh.va2`. Home Assistant removed `fan.set_speed` in
  2023.7 and these two were missed when the other models were moved to
  `fan.set_preset_mode`. On `zhimi.airfresh.va2` the dropdown was empty as
  well, because it read its items from the `speed_list` attribute, which went
  away at the same time.
- Documentation links inside HACS. The reference moved into `docs/` in 3.1.6
  with relative links, and HACS renders the README through the Home Assistant
  frontend, where a relative link resolves against the wrong host and leads
  nowhere. All links are absolute now.

  HACS renders the README from the tag of the version you have installed, so
  this only takes effect once you are on 3.2.0.
